# ESP32 펌웨어

`KNOK_ESP32_Recorder/`: GPIO2 제품용 6초 자동 녹음 시연 펌웨어. `gpio2-fast/`는 같은 소스의 별도 사본입니다. `gpio11/`은 다른 제품을 위한 GPIO11 펌웨어입니다.

각 스케치 폴더에서 `secrets.example.h`를 `secrets.h`로 복사한 뒤 2.4 GHz Wi-Fi 정보를 로컬에서 설정합니다. 이 파일과 빌드 결과물은 공개하지 않습니다. 마이크 GPIO4/5/6, 기울기 GPIO8, LED GPIO7 및 피에조 GPIO2 또는 GPIO11을 실제 배선과 대조하세요.

GPIO2 버전에서 짧은 녹음이 앱에 도착한 사례는 있으나, 자동 감지 재무장·Wi-Fi 타임아웃·책상 두드림 오분류는 해결 검증이 필요합니다. 피에조를 자동 분류 결과에 합산하는 기능은 검증되지 않았습니다.
